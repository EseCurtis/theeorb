# Project docs (boilerplate)

Fill these in when you start a product. Agents read them for product context.

| File | Purpose |
|------|---------|
| `prd.md` | What we're building, MVP scope, users |
| `design-guide.md` | Visual language, tokens, UI principles |
| `rules.md` | Product-specific UI/content rules (not code layout) |
| `TODO.txt` | Human + agent backlog |

Code layout lives in `.agent/Server.RULES.md`, `.agent/Frontend.Mobile.RULES.md`, `.agent/Frontend.Web.RULES.md`.

Session continuity lives in `.agent/shared-mind.txt` and `.agent/Agent.Continuity.RULES.md`.
