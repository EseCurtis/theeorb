# Thee Orb — project context

Thee Orb is a living social arcade. A person raises an AI avatar—an Orb—then releases it into a shared world where it acts while they are away.

| File | Purpose |
|------|---------|
| `prd.md` | Product definition, MVP boundary, users, and open decisions |
| `design-guide.md` | Brand, visual language, UX patterns, and accessibility direction |
| `rules.md` | Product-specific content, behaviour, economy, and UI constraints |
| `TODO.txt` | Ordered backlog for the next implementation slices |

Code structure is governed by the surface-specific rule files in `.agent/`. Session continuity is governed by `.agent/shared-mind.txt` and `.agent/Agent.Continuity.RULES.md`.
